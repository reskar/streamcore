# Architecture Decision Records

Короткие записи про значимые архитектурные решения и их причины. Один
файл на решение, не редактируются после принятия — для пересмотра
заводится новый ADR со ссылкой и статусом `Superseded by ADR-XXXX`.

Имя файла — `NNNN-kebab-title.md`, 4-значная нумерация начиная с `0001`.
Структура: Status, Date, Context, Decision, Consequences, опционально
"Когда пересмотреть".
